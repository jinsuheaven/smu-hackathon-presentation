# 전력수요와 송전 인프라의 공간적 불균형 분석

숙명여대 Snowflake Summer Camp 해커톤 발표용 저장소입니다.
**전력수요가 높은 지역에 송전 인프라가 충분한지 살펴보고, 제조공정의 생산시간 조정으로 피크전력을 줄일 수 있는지 분석했습니다.**

## 30초 핵심 결과

- 면적 차이까지 보정한 결과, **전남·경북·충남**이 상대적 송전망 부담 가능성 상위 지역으로 나타났습니다.
- 송전망 부담과 건강부담은 양의 상관 경향이 있었지만 **통계적으로 유의하지 않았습니다** (`r=0.420`, `p=0.094`).
- 제조공정 전력예측 모델은 **R²=0.8995**의 성능을 보였습니다.
- 생산량을 유지하면서 고부하 시간대 생산의 40%를 분산한 결과, 평균 피크전력이 **약 1.06% 감소**했습니다.
- 전남은 지역 전력 고부하 시간과 제조공정 고부하 시간이 **80% 중첩**되어 수요관리 우선 적용 사례로 제안했습니다.

## 분석 흐름

**전력시설 공간 분포** → **지역별 전력수요 분석** → **면적보정 송전 인프라 비교** → **건강부담 보조 분석** → **제조공정 전력예측** → **생산시간 분산 시뮬레이션**

- **Snowflake:** 원본 적재·정제, `GEOGRAPHY` 변환, 공간 결합 및 지역별 집계
- **Jupyter:** 통계 검정, 모델링, 시나리오 분석 및 발표 시각화

## 해석 시 주의사항

본 결과는 설비용량·선로 부하율이나 전남 개별 제조업체의 실제 감축량을 직접 측정한 것이 아닙니다. 따라서 **‘송전망 부족’이나 인과관계를 확정하는 결과가 아니라, 지역별 상대적 부담 가능성과 수요관리 적용 가능성을 탐색한 결과**로 해석합니다.

원본 데이터, 인증정보 및 개인 로컬 경로는 공개 저장소에 포함하지 않았습니다.
